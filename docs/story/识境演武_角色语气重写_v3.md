# A｜开场

*识境。山门有太虚山的轮廓，入门却是宽阔的演武场。廊下挂着灯，树影映在台阶上。小识站在石阶最高处，似乎已经等了一阵。门边有块盖着布的牌匾。*

A01-05 小识：当然不能一模一样。你以前那座山，连条打架不磕脚的路都没有。

*小识抬手，庭中出现五道身影，容貌都与她相同，动作却不尽相同：有人站得稳，有人拖着步子，有人已经在跃跃欲试。*

A01-09 小识：都是我做的。你要是觉得跟我一个模子刻出来的，那就大错特错了。

A01-10 符华：出招习惯不一样。

A01-11 小识：哼，眼力不错。各管一关。前五场你赢了，就从三种变化里挑一种带到下一场。怎么挑，我不管。

A01-17 小识：不然呢？叫你来跟五个木头人打完就走？那多没意思。

## 演出与文本校对备注（不在游戏内显示）

**人物语气**：小识话多、好胜、爱卖关子，但她真正懂自己做的招，不是等待符华纠错的倒霉设计师；会直接夸人，也能坦然承认一场败仗。符华观察认真、尊重对手，话短并不等于冷漠；幽默来自自然反应而非持续抬杠。两人已经熟悉，既能争两句，也可以不说话。

**战斗剧情**：选卡分支以武学差别为主，不硬给每张卡加人生道理。第一次通关的剧情回报是小识认真办成了一件事，符华真想再来；两人都无需演讲。这是游戏节奏上的选择，不是说原作不存在严肃主题。

**程立雪**：符华亲手为立雪做云吞面是既有背景，不另编详细的生日时间、配方或死因。I02 的童年画面采用不指定具体日期的记忆片段，避免与原作回忆冲突。小识拥有相关记忆，但对这份记忆的主观感受和符华未必相同；因此她说「我知道」，却不会冒充自己亲历了同样的人生。

**制作成本**：J01 可删，I02 回忆可仅用厨房灯影、桌面云吞、程立雪一句音频和两帧静帧完成；不需为回忆制作完整场景或高强度剧情战斗演出。

**原作对照（参考而非复制）**：

- 主线第37章与第39章中小识的实际对话：她的行动力、知识、突发奇想和直截了当的关照。
